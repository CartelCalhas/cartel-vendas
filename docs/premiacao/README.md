# Troféu Cartel Calhas — Programa de Premiação e Reconhecimento

Programa de premiação e reconhecimento dos funcionários da Cartel Calhas, com
categorias para Vendedor, Fabricador, Entregador e Funcionário Destaque do
Mês. Cobre critérios e pesos, pontuação de 0 a 100, valores em R$ (mensal,
trimestral e anual), regras de desempate e disciplinares, modelo de
certificado e modelo de ranking mensal.

- **Manual completo (visual):** publicado como página — peça o link ao
  responsável pela sessão que gerou este material, ou veja o histórico de
  artifacts em claude.ai/code/artifacts.
- **Planilha de acompanhamento:** [`Cartel Calhas - Programa de
  Premiacao.xlsx`](<./Cartel Calhas - Programa de Premiacao.xlsx>) — 7 abas
  (Instruções, Vendedores, Fabricadores, Entregadores, Destaque do Mês,
  Ranking Mensal, Histórico Trimestral e Anual), com fórmulas de pontuação
  já prontas e testadas. Contém funcionários de exemplo fictícios — troque
  pelos dados reais da equipe antes do primeiro uso oficial.

Este material não faz parte do funcionamento do bot de WhatsApp deste
repositório; está aqui apenas como registro/versionamento do programa de
RH da empresa.
